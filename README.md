# SCPT_tool

This tool is designed to automate the Vs interpretation process from SCPT. As of May 15, 2026, the direct interpretation tool is available in the folder with sample files. All-in-one tool is a conprehensive tool set for SCPT - Vs interpretation or Vs estimate from CPT data. The tool is currently at beta stage, more features will be added to the tool at its official release.
